# Write Product Slice

## Read

Verify the canonical workspace and minimal preflight. Add vision, tech stack, live candidates, and policy only.

## Guardrails

- No concrete current user problem means no full slice/spec process.
- Keep one to three candidates. Archive replaced proposals rather than accumulating them.
- Identify the likely lane; uncertain or sensitive work is `controlled-change`.

## Steps

1. Confirm the problem, outcome, likely areas, and non-scope.
2. Propose one to three candidates with likely lane and main risk.
3. Recommend the smallest user-visible outcome.
4. Update current planning docs only, set the planning phase, and stop for human scope approval.

## Output

Give compact options, recommendation, and approval request. A formal PR will carry live implementation evidence.
